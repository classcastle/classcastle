Frequently asked questions

Is Classcastle for Windows out yet?

Not quite! It is currently in active development and coming soon. Sign up above to get early access notification.

Do teachers use the Windows app?

No. Teachers continue to run and manage their rooms from the standard teacher web app. The Windows app is exclusively for students to join rooms.

Is the Windows app free?

Yes, just like the web platform, Classcastle is 100% free for educators and students.

What Windows versions will be supported?

The desktop app will fully support both Windows 10 and Windows 11 across standard x86-64 and ARM architectures.

Can students still use the browser extension?

Yes. The Windows desktop app is an alternative native option for schools preferring standalone Windows applications over browser extensions.

How is student data handled?

We only process student display names, connection status, and active tab URLs strictly for the teacher dashboard. No history is stored or sold.
