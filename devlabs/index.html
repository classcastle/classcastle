Getting started

Generate your API key, then make your first request. Or use the code generator to quickly generate API request code.

1. Generate your API key

Go to devlabs.classcastle.org/generateapikey to generate your API key. This creates an API-only account that can only be accessed via the API, keeping your main teacher account secure.

2. Authenticate your requests

Include your API key in the Authorization header as a Bearer token.

Authorization: Bearer your_api_key_here

3. Check system status

Before making API calls, check the Classcastle status page to ensure all systems are operational. The status badge in the main site header also shows current system status in real-time.

4. Use the sleep helper

The classcastle.sleep() helper lets you add delays between API calls. Pass the number of seconds to wait.

classcastle.sleep = (seconds) => new Promise(resolve => setTimeout(resolve, seconds * 1000)); // Wait 2 seconds before the next action await classcastle.sleep(2);

5. Make your first request

Create a room to verify everything is working.

curl https://api.classcastle.org/.netlify/functions/createroom \ -H "Authorization: Bearer your_api_key_here" \ -H "Content-Type: application/json" \ -d '{"name": "Test Room"}'

Example: Create, navigate, and delete

A complete example showing how to create a room, send students to a page, and delete the room when done.

// Helper function to sleep/delay classcastle.sleep = (seconds) => new Promise(resolve => setTimeout(resolve, seconds * 1000)); // Create a new room const response = await fetch('https://api.classcastle.org/.netlify/functions/createroom', { method: 'POST', headers: { 'Authorization': 'Bearer your_api_key_here', 'Content-Type': 'application/json' }, body: JSON.stringify({ name: 'Period 3 - Science', trycode: 'SCI3' }) }); const room = await response.json(); // Wait 2 seconds before navigating await classcastle.sleep(2); // Navigate all students to a URL await fetch(`https://api.classcastle.org/.netlify/functions/rooms/${room.id}/navigate`, { method: 'POST', headers: { 'Authorization': 'Bearer your_api_key_here', 'Content-Type': 'application/json' }, body: JSON.stringify({ url: 'https://microbit.org' }) }); // Delete the room when done await fetch(`https://api.classcastle.org/.netlify/functions/rooms/deleteroom/${room.id}`, { method: 'POST', headers: { 'Authorization': 'Bearer your_api_key_here', 'Content-Type': 'application/json' } });

Troubleshooting

Common error codes and how to resolve them.

409
Room code already exists
When using the trycode parameter, this error means the code is already in use by another room. Try a different code or omit the parameter to let the system generate one.
401
Invalid or missing API key
Check that your Authorization header includes a valid Bearer token. Generate a new key at devlabs.classcastle.org/generateapikey if needed.
404
Room does not exist
The room ID you're trying to access doesn't exist or you don't have permission to view it.
400
Invalid room code or URL
The room code must be exactly 6 digits (numbers only). The URL must be valid and start with http:// or https://.
429
Too many requests
You've exceeded the rate limit for API calls (60 requests per minute). Wait a moment before retrying, or contact us about increasing your limit.

Error response format

All errors are returned in the following JSON format:

{ "error": "Error message here" }
