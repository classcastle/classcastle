Test a Classcastle OAuth app

Enter the credentials for a registered app to test the authorization and consent flow. This page uses Authorization Code with PKCE and does not send your client secret to the browser.

This must exactly match a redirect URI registered for the client. Register this page URL before testing.

Use a space-separated list, such as openid profile email classrooms.

Testing note: The authorization code is short-lived and should be exchanged by your server. Never put a client secret in this page or in browser JavaScript.
