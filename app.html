IT Deployment Guide

Share this information with your IT department to deploy Classcastle across your school

01. Extension ID

Share this ID with your IT team. They'll need it to force-install the extension across your school's devices.

Extension ID: abcdefghijkabcdefghijk

Note: This is a demo ID. In production, this will be your actual Chrome Web Store extension ID.

02. ChromeOS / Chrome Deployment

Add the extension to your Google Admin console under Device Management > Chrome > Apps & Extensions.

{ "ExtensionInstallForcelist": [ "abcdefghijkabcdefghijk" ] }

03. Edge Deployment (Intune/GPO)

For Microsoft Edge, deploy via Intune or Group Policy using the extension ID.

Registry key: HKLM\SOFTWARE\Policies\Microsoft\Edge\ExtensionInstallForcelist Value: 1;https://edge.microsoft.com/extensionstore/abcdefghijkabcdefghijk

04. Network Configuration

Safelist these domains in your web filter or firewall to ensure room connections work properly.

*.supabase.co *.classcastle.org

05. Testing

Before full deployment, test on a single device to ensure the extension appears and can join a test room.
