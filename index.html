For IT: rolling it out across a fleet

You don't need every student clicking install one by one. Push the extension centrally and it's ready before the first lesson.

01

Get the extension ID

Find Classcastle's ID and store listing under Admin → Deployment in the teacher app. You'll use this ID in your policy.

02

Force-install through policy

Add it to ExtensionInstallForcelist in the Google Admin console for ChromeOS and Chrome, or push it via Intune or GPO for Edge. No end-user action required.

03

Allow the connection

Safelist Classcastle's domain in your web filter or firewall so room connections aren't blocked on the school network.

04

Verify on a test device

Confirm the icon appears pinned and can join a test room, then roll out to the rest of the fleet with the same policy.

Frequently Asked Questions

Is Classcastle free?

Yes, Classcastle is free for teachers. Create unlimited rooms, invite unlimited students.

What browsers does it work with?

Chrome, Edge, and any Chromium-based browser. Works on Windows, macOS, ChromeOS, and Linux.

Do students need accounts?

No. Students only need the extension and the room code. No signup, no login, no email required.

Can students navigate on their own?

Yes. Classcastle doesn't lock their browser — it just pushes URLs. Students can still navigate independently if needed.

What if a student's extension isn't working?

Students without the extension simply won't receive navigation commands. They'll still appear in your room list but won't sync.

Is student data collected?

We only collect what's needed: student name (for identification), online status, and the current URL for the teacher dashboard. No browsing history or tracking.
